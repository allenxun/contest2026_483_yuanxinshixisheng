## 实现与限制

使用原版 wpa_supplicant 2.12 的 WPA 状态机和密码算法，源码位于 `app/k7radio/hostap/`，原始许可证与逐文件来源记录一同保留。`skw_supplicant.c`、`skw_supplicant_os.c` 与 `skw_wpa_transport.c` 将 EAPOL、密钥和定时器接到原生无线驱动；随机数通过已运行的蓝牙控制器 HCI LE Rand 获取，失败不使用弱随机数替代。

已通过实际状态机的主机测试：已知 PMK、M2 MIC、PTK/GTK 安装、错误 MIC、旧帧重放以及 M3 重传不重复安装密钥。此结果不代替真机错误密码、换热点、长连接或重新联网测试。

当前认证诊断限定 Lansee、WPA2-PSK/CCMP、20 MHz 基础 STA 模式；不宣称支持 WPA3、企业认证或所有路由器。原生数据帧与 DHCP 接入位于 `skw_wifi_data.h`、`skw_netdev.c`、`wifi_ip_service.inc`，属于独立 `wifi-ip-20260909` 开发版本。数据解码已通过边界、接收地址、每 TID 重放和 RSC 溢出测试；IP 真机结果以本文件后续记录为准。
