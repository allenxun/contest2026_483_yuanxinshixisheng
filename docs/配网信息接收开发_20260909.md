# 配网信息接收开发记录

用户将当前目标限定为 BLE 联动闭环：真实 Wi-Fi 扫描、选择网络和提交密码、设备确认收到；不要求立即完成 Wi-Fi 联网。随后明确要求临时启动新版本供前端测试。本轮不刷 eMMC/STM32，不启动云台。

## 实现

`prov_protocol.c/h` 增加 `submit_credentials`、严格规范 Base64 SSID 解码（1..32 字节）、密码规则（8..63 可打印 ASCII），保留首尾空格、引号和反斜杠。失败时擦除输出中的敏感内容。

`prov_service.inc` 增加 `receive_credentials:true`，在既有加密、订阅、串行事务和 session 隔离下接收字段。密码仅用于格式验证，回复前擦除，不落盘、不保留用于稍后自动联网；回包为 `credentials_received`，包含 id、session、validated:true、stored:false、wifi_connected:false、ip:null。此回包不证明密码正确，只证明接收和格式校验通过。

前端增加 `submitCredentials()` 与示例 `submitWifiDetails()`；旧固件缺少能力时继续禁用。终态必须匹配 id 和 session，拒绝把“已收到”误报为联网。完整配网按钮仍关闭。

## 同轮已完成的后续认证准备

`skw_wpa_transport.c/h` 实现命令 15 的 EAPOL 参数发送、CCMP 命令 12/13、ACK 错误传递、重复密钥安装拒绝、超时安装后的删除尝试及敏感缓冲清理。生命周期挂接到关联探针，接收信息接口不调用它。发送和安装函数仍没有被 WPA 状态机实际调用，不能称为握手已运行。

命令布局依据本地官方 SDK 的 `skw_iface.h`、`skw_cfg80211.c/h`、`skw_msg.h`。48 字节 key params 中 key[32] 的宏值核对 [Linux v6.1 ieee80211.h](https://raw.githubusercontent.com/torvalds/linux/v6.1/include/linux/ieee80211.h)。官方 RX 重放计数保存在主机，不能拿 TX PN 替代；主机数据重放过滤、WPA 状态机、可信随机源、netdev/DHCP 仍未完成。
