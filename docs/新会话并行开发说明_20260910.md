# 新会话并行开发说明

可以并行推进软件任务；同一块板、COM8 和 Ubuntu 编译工作区不能由两个会话同时控制。新建聊天本身不会隔离文件。

## 当前分工

| 会话 | 负责范围 | 验收方式 |
| --- | --- | --- |
| 当前主会话 | DDR、eMMC、SMP/BSP、无线板端、固件集成 | 编译及有界真机验证 |
| 建议的新会话 | VoiceLink 状态机、音频数据转换、模拟网络接口、主机测试 | 独立目录中的可复现测试及接口文档 |

新会话输出先放 `E:\openvela\VelaVision\work-in-progress\parallel-voicelink`，原 VoiceLink 模块只读。该目录属于统一仓库，不形成另一个产品入口；完成后由主会话核对补丁并集成。当前仓库有大量未提交文件，不能假设从 HEAD 新建的工作树含有最新代码。

Codex 也支持独立工作树：[官方说明](https://learn.chatgpt.com/docs/environments/git-worktrees)。若采用工作树，必须先确认未提交源码完整进入工作树，并为该会话显式登记日志采集范围；现有采集器不能保证自动收录主项目之外的工作树。不要复制私密配置或模型全集。

## 合并时检查

1. 比较输入哈希，确认主会话期间是否改过同一接口。
2. 核对模拟结果和真机结果分别标注；保留失败与未完成项。
3. 由主会话迁入正式源码、审计 SDK 同步并编译，再安排硬件测试。
4. 日志归属 maomaojiang01，核对新会话确实入库、官方格式校验通过。
