# USB 只读模型存储接入

用户已将 U 盘插入 K7 USB HOST，保留串口调试线。本轮目标是枚举和有界块读取；不格式化、不写 U 盘、不挂载 FAT、不加载模型。

独立版本 `usb-readonly-20260910`，RAM镜像 SHA256 `a40d6068de181146973eda4a4fede21183210e5714339354f58fa3779e583374`；ELF SHA256 `a0bafc30267c061323980e8603fa3085a4279402d0aee26ffdeab771ab439cb9`。实际ARM64完整构建通过，三个目标编译单元确认MSC和只读选项生效、FAT关闭。异常表340 FDE及首初始化注册检查通过，驻留6,504,448字节，在独立8MiB门禁内。编译/ELF通过不是设备验收；加载和实际运行以 `project-manifest.json` 与证据目录为准。

## 本轮变更

- MSC类在xHCI启动之前注册，只有显式 `k7storage start` 才启动控制器。
- `CONFIG_USBHOST_MSC_READONLY` 默认关闭；开启时拒绝块写，geometry报告不可写；READ10最多4KiB，检查容量及范围。
- 检查CBW、数据、CSW完整长度及签名、事务tag、residue、状态；传输失步后实例闭锁，不盲目重发。
- `k7storage list` 传播目录读取/关闭错误，目录项计数有上限。
- `k7storage read /dev/sdX` 只对人工核对的新USB节点执行，两次读取LBA0并比较；不输出盘内正文。

首次目标构建因未使用debug函数在严格Werror下失败，原日志/源码哈希保存在 `evidence/build/usb-readonly-20260910/attempt-1/`。修复为完整CSW校验之后才调用已有调试函数，重新审计同步后构建通过；没有关闭编译告警。

## 候选和边界

A的MSC mock回放31组、C的真实诊断源码mock，以及A的输出验收器分别保留独立证据；它们不证明真实U盘功能。GET_MAX_LUN控制接口不返回实际字节数，不能宣称已检查其响应长度。传输观察超时不强杀任务、不推测DMA已停止。

FAT只读候选尚未集成。当前NuttX中MS_RDONLY不足以保证FAT不写介质，后续需独立启用FAT强制只读和下层MSC写阻断。FAT stat的设备/文件身份字段为零，不能凭这些字段证明两个路径打开是同一文件。固定llama loader仍重新按路径打开，模型reader默认门禁保持关闭，等待同句柄及媒体生命周期约束落地。

此前 `arena-provider-20260910` 已真机验证32KiB模型池ggml缓冲区、8192项set/get和释放，BLE真实配网、30秒保持、网关5/5通过。新固件不沿用该无线运行结果，切换后须重新检查。

没有写入eMMC/STM32，没有启动云台，没有远程提交。
