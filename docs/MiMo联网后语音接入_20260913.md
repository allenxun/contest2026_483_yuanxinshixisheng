# MiMo 联网后语音接口

用户选择 mimo-v2.5-asr 和 mimo-v2.5-tts。用户提供的密钥属于 Token Plan 类型，本文不包含密钥。尚未发起实际 API 调用，不能确认套餐有效或账号权限。

依据官方 https://mimo.mi.com/docs/en-US/tokenplan/Token%20Plan/quick-access ，Token Plan 使用套餐控制台指定的 Base URL。中国集群为 https://token-plan-cn.xiaomimimo.com/v1 ，另有新加坡/欧洲集群。必须按账号控制台确认，不能将 tp 类型密钥混用到普通按量计费地址。

ASR：POST BaseURL/chat/completions，model=mimo-v2.5-asr，用户消息为 input_audio，WAV 或 MP3 编码为 Base64；可指定 asr_options.language=zh，响应 choices[0].message.content 为转写文字。官方 https://mimo.mi.com/docs/en-US/api/audio/Speech-Recognition 。

TTS：同为 chat/completions，model=mimo-v2.5-tts，待播报文字放在 assistant 消息 content，audio 指定 wav 和内置 voice（如 mimo_default）；返回 message.audio.data 的 Base64 音频。官方 https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/speech-synthesis-v2.5 。

工程顺序：先完成界面配网并取得真实 IP，再验证 DNS、TLS 证书和 HTTPS，最后调用云端语音。板端工具执行及真实结果判断仍由本地控制层完成；首次离线配网不能依赖云端。已给日志导出器补充 Token Plan 密钥脱敏规则。
