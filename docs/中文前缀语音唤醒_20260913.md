# 中文前缀语音唤醒（2026-09-13）

用户先将品牌唤醒词改为“开始联网”，随后进一步明确：“你好”“你好联网”都可通过，只要以“你好”作为前缀即可。当前正式代码据此接受归一化后以“你好”开头的文本，同时保留完整短语“开始联网”。这是用户对本机测试规则的明确调整，不再沿用旧品牌名全等条件。

前缀规则仅用于等待唤醒状态，命中后开始真实 Wi-Fi 扫描；网络序号、密码字符和提交确认仍各自校验。“不要你好”“关闭了”不触发唤醒。模型理解或播报不能替代真实设备联网结果。

本次同时把正式 `k7sound_play_prompt_tone()` 改为已实听的最大档短音，保持用户要求的提示音音量；通用 `native_asr_runtime.cpp` 日志只保留识别耗时和输出长度，不打印识别原文，避免密码轮留下原文。单独的唤醒诊断仍可打印非密码唤醒文字。

20 组正式文本流程在 O0/O2 通过；新增测试验证前缀唤醒不能充当网络选择或密码。ASR 模拟运行的输出边界、失败清理、帧数限制与并发检查通过，并验证修改前日志包含公开测试标记、修改后不包含。主机测试不代表板端语音识别通过。
