# K7 板载喇叭与麦克风

用户已明确确认麦克风接在 MIC。最新近照可追踪喇叭双线插入 SPK 喇叭座；保持当前接法，接线照片不代替录放音测试。此前照片遮挡导致的 MIC/FAN 疑问已由用户确认消除，不再重复要求确认。

## 目标与真实状态

采用现有板载音频接口，不要求改用 USB 耳机。先把 I2C3、ES8388兼容codec和SAI1接通，再分别做低音量短播放与短时录音。随后才连接VoiceLink的ASR/TTS与Agent，不能把主机模型运行结果当板端语音已经完成。

冻结原理图：SPK1/J7400、SPK2/J7401是功放差分输出；MIC/J7001接LIN2/RIN2模拟输入；FAN是独立风扇接口。SDK DTS对应I2C3 M0、7位地址0x10及SAI1 M0。已有Linux es8323兼容驱动仅作该SDK参考；完整板端录放音驱动尚未集成。

## 后续接入顺序

1. 主会话独占串口和板子；存储测试与音频首次接管不在同一轮同时执行。
2. 在单独音频固件核对I2C3访问和codec控制，功放保持关闭。
3. 核对时钟、SAI1格式、缓冲区所有权及停止路径后，分别验证播放和录音。
4. 记录原始PCM、实际采样格式/帧数、错误/溢出和资源恢复；播放需实际听辨，录音需实际信号验证。
5. 通过后接入现有VoiceLink候选及共享网络事务，密码继续走规则解析器。
