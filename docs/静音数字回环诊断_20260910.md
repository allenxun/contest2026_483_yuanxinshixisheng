# 静音数字回环诊断

目标是用SAI内部固定数字标记隔离真实麦克风/codec输入，判断周期性三零现象是否仍出现。它不是音质滤波，不使用扬声器输出作判断。

`audio-loopback-20260910` 增加显式 `k7sound loopback`：同一SAI1共享CKR/FSCR主时钟、I2S32、16k名义帧率，PATH的SDI0临时选择内部SDO0。codec维持PREPARED/mute；runner仅有强制功放低并读回的回调，没有开启功放接口。固定128对、预计8ms，截止为帧时长+5ms、循环预算有界；前64次TX及RX访问记录时间、FIFO前后值及原始字。原麦克风缓冲不改，诊断使用独立512字缓冲和静态结果。

退出同时停止TX/RX、确认idle，在CLK/FS仍开启时清两FIFO，最后关CLK/FS；只有成功停止后才恢复PATH并读回。任何停止/恢复不明均保留held，不继续平台断钟。接入时同时修正主命令错误清理：停止失败、data_held或reset_fault必须锁存platform.held，防止此前分支在未执行sap_cleanup时仍落到恢复时钟门控。成功路径不变。

候选来自 `work-in-progress/parallel-neon-probe-medium/audio-zero-pattern-v2/duplex-runner`，输入及交付哈希已核对，O0/O2有界模拟与失败注入通过。正式编译、ELF/raw一致性通过，镜像运行空间7307264字节，8MiB门禁余1081344字节。镜像SHA256为 `63735a3140e3992ed11ff7f8bfbae62c61d5cee50b4107ad4f6358348b1dc913`。板端结果以 `evidence/audio-loopback-20260910/` 原始记录为准；本文初建时正在RAM加载，不能将其记为已实测。

八种标记表示入队次序，不能先验命名为银行0..3。若内部仍三零，codec不是必要条件，但也可能是TX布局；若内部完整，仍需排除TX/RX错误互相抵消。记录完整原始零值，不靠对齐删除或重采样宣布修复。
