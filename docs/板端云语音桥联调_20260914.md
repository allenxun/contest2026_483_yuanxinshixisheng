# 板端云语音桥联调

本轮目标：App BLE 配网后，K7 通过局域网开发语音桥使用阿里云流式 ASR 和云 TTS。上游 Key 只在原 speech-service 进程内读取。当前桥监听电脑 TCP 8001，原 HTTP/WebSocket 服务为 8000。这是显式局域网开发通道，尚不是带设备认证/TLS 的正式部署。

## 接口与源码

- 板端 `app/k7agent/cloud/src/board_speech_bridge.c`。
- 服务端 `host/streaming_asr/board_bridge.py`，转接现有 `/asr/stream` 与 `/tts`。
- `k7cloud asr-live 10.3.1.125`：云端 ready 后开始三秒麦克风采集，150个20ms帧；独立线程接收 partial/final，最后 completed。当前串口只记录事件类型，不输出真实识别文本；原文仍在上游事件内，不持久记录。
- `k7cloud tts-test 10.3.1.125`：云端合成固定文本“联网成功”，下载单声道16kHz S16LE PCM并调用板端播放。不是自动配网播报，也不是流式TTS。

板端到开发桥为有界 TCP 包：五字节模式 K7S1A/K7S1T，然后一字节类型、四字节大端长度、正文。音频 A 正文为四字节小端序号加640字节PCM；E结束；J返回JSON事件。T提交UTF-8文本；D返回完整PCM；X表示失败。TTS限制30秒/960000字节，ASR目前板端限制三秒。队列溢出取消，不能悄悄丢帧。
