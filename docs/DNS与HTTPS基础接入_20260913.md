## 21:48 云端接续审查

语音配网与云端请求分为两个所有权域：VoiceLink 在收到真实 `IpReady` 后结束配网；独立 `CloudSupervisor` 读取只读网络租约快照，再依次执行 DNS、信任前置、TLS 与 MiMo 请求。租约快照至少包含 generation、链路/DHCP 状态、接口、IPv4、网关和最多两个 DHCP option 6 DNS 地址。断链或 generation 变化必须取消旧 DNS/TLS/API 请求，不能把云端失败回灌为密码错误。

当前最小缺口已经固定为：DHCP option 6 注册与清理、版本化租约快照、有界非阻塞 TCP connector、可信熵、可信时间、最小 CA、离线语音与云端能力合并配置、MiMo 官方嵌套 JSON/Base64 profile。现有 `k7cloud status` 仍只证明组件链接，不能作为互联网或 API 验收。
