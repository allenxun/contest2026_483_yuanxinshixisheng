## Agent 加在哪里

Agent 属于 RK3576 应用层，放在用户输入与机器人能力接口之间。拟新增 `app/k7agent/`（尚未创建/实现）。任务执行器调用视觉、拍照、云台等明确接口；STM32 继续执行实时控制。Agent 不直接随意拼串口字节或绕过设备控制入口。

例如“找到仪器并拍照”：解析任务 → 检测 → 判断目标位置 → 调整云台 → 等待稳定 → 拍照 → 返回结果。每一步都需要实际状态、超时、取消与失败回报；模型文本不能代替动作完成证据。

比赛开发流程用的 `SKILL.md` 与机器人运行时 Skill/Tool 是不同交付：前者沉淀开发步骤，后者描述能执行的机器人能力、参数及结果。

## 接入时机

1. Wi-Fi 基础认证、DHCP 和网关通信已有实测；当前补 BLE 长稳、正式配网和构建复现。
2. 随后接最小文字指令流程，先读真实状态，再接单次拍照，不必等 NPU 全部完成；跟随动作另行验收。
3. 完成 NPU 模型运行时、仪器检测后，将经过验证的新能力接到相同接口。
4. 再加入语音输入、整机协同和最终部署验收。

云端模型与离线模型尚未选定；联网并不意味着必须使用云端。完全离线需要另行验证模型资源与推理能力。现阶段不能可靠承诺完整交付日期。
