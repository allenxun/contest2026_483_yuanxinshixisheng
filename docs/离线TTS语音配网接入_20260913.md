## 本次实现

- `native_speech_output.hpp` 接通真实 Sherpa TTS、8 kHz 到 16 kHz 插值及板载 PCM 播放。每次文本最多 180 字节，按 UTF-8 边界分段；只有最后一段可进入录音。
- `k7sound_speak_pcm` 支持最多 30 秒的 16 kHz 双声道 S32 播放，沿用音频 owner、停止和寄存器恢复检查。可在播报前准备 ADC，结束后直接录音，避免重新准备麦克风截断句首。原录音仍限制 48000 帧。
- `flow-mic-provision` 在显式 TTS 构建中使用真实播报。等待唤醒时每轮播报“还没有联网，请说你好联网”；其他输入轮播报“请说话”。ASR 与播报顺序执行，非同时全双工监听。
- 网络编号及密码字符数用中文数字；英文 SSID 按字母拼读，常见下划线、横杠、点有明确名称，其余 ASCII 符号暂播“符号”。实际连接始终使用原始 SSID。中文 TTS 原词典会忽略英文 SSID，不能把非空 PCM 当作读出了名称。
- 密码逐字符输入，支持大小写、删除、清空、完成和确认提交；不播报完整密码，不记录识别出的密码字符。全语音长密码准确率和耗时尚未验收。
