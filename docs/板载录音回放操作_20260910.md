# 板载麦克风录音 → 板载喇叭回放

当前用于音频诊断，尚未完成语音质量验收。短音可听不等于录下的人声已能清晰播放；每个版本的实听结果必须单独保存。

## audio-gain-20260910 命令

由主会话独占 COM8，在该镜像通过校验并 RAM 启动之后执行。不要同时运行其他串口程序。

1. 提示说话后运行 `k7sound capture 48000`。初始化后等待约1秒，再采集名义16kHz的48000对数据，约3秒。
2. 检查 `pio=0 frames=48000 stop=0 held=0` 和最终各清理返回值为0。该结果只代表搬运完整，不代表音质通过。
3. 执行 `k7sound replay-max`，将刚采集的原始缓冲送给板载喇叭。最大档位是 DAC 两路0dB、OUT2两路+4.5dB，不做PCM增益、删零、重采样或左右平均。
4. 用户确认是否听到自己说的话，以及清晰程度。没有声音、只有噪音或失真都保留为未通过。
5. 使用 `k7sound dump` 保存原始串口PCM；`tools/extract_k7_audio.py` 可生成不归一化的原始32位/高16位WAV。

录音保留在 RAM，重启即失去；新一次 capture 会替换旧录音。replay 和 tone 不覆盖录音。测试完成后关闭功放并恢复外围配置。

其他对照入口：

- `k7sound replay`：旧默认音量，DAC−24dB、OUT2−15dB。
- `k7sound replay 6`、`12`、`18`、`24`：只减少DAC衰减，分别相对默认增加对应dB，OUT2仍为−15dB。
- `k7sound tone`：原默认200ms短音；`k7sound tone-max`为最大档位200ms短音。
- 最大档位由本次显式命令设置，下次默认命令仍重新使用原默认值。
