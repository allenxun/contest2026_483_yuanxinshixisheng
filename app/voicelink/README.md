# 本地语音配网核心

近期目标：本地唤醒 → 真实 Wi-Fi 扫描 → 按编号选网 → 逐字符密码输入 → 独立口头确认提交 → 异步请求连接 → 真实 IP 成功后播报。云端小米 API 在联网后另行接入；本组件不依赖 llama.cpp 或云端模型。

`src/core.cpp`、`src/parsers.cpp` 和四个头文件来自已验收的 `work-in-progress/parallel-voicelink`，迁移前核对交付哈希。初始迁移记录在 `evidence/voicelink-core-integration-20260910/migration.json`。正式核心修正了“不支持/找不到网络”仍停留密码输入的问题，改为返回选网；原候选未修改。

这是正式源码中的独立核心组件，已经注册到当前 RAM 诊断固件。没有复制旧同步 WAPI 平台实现或模拟成功后端。主机测试输入的是识别后的文字，扫描/IP 均由明确的模拟端口提供；真实板端结果单独记录，不能混算。

复现（项目根目录）：

```powershell
python tools/test_voicelink_flow.py
```

调度要求：Controller 由同一个语音任务串行调用；扫描/连接期间即使 ASR 无结果也应定期调用 `poll()`。正式接口改为 `beginScan/pollScan/cancelScan`，默认30秒请求期限，Ready快照最多64条；过滤和排序后最多播报5个网络。实际硬件扫描必须安排在专用工作任务并通过共享无线服务仲裁，不能在 BLE 回调或 LPWORK 中直接执行。扫描接受不等于列表已就绪；取消只是请求，服务必须保留租约直到底层清理确认。旧同步平台适配器不兼容这个接口。

“完成”只进入确认态，不提交密码；只有随后独立识别到“确认”或“确认提交”才允许调用无线端口。否认、重输、取消、超时和析构都会擦除密码。开放网络也需要独立确认。

连接返回 CredentialsReceived/Connecting 都不是成功；只有该事务的 IpReady 加有效 IPv4 才能播报已连接。19个正式路径主机流程覆盖异步扫描、取消/超时/旧事务隔离、忙/不支持、结果上限、真正空列表、选网、确认门禁、密码提交及IP成功，所有音频/网络端口均为模拟。

板端尚缺：统一扫描租约与真实网络后端、I2C3/codec/SAI录放音、实际ASR/TTS库与模型、真实声音验证及无线共存回归。密码仅进本地规则与网络认证，禁止写日志或提交云端。开放网络与在线扫描是否可用以真实后端能力为准，不能照旧模块说明假定支持。

`k7voice flow-scan` 是板端集成门禁：它用正式 Controller、真实共享 Wi-Fi 端口和控制台提示执行到候选网络状态，不接收或提交密码。该命令通过只能证明控制器与真实扫描后端已链接，不能代替 ASR、喇叭提示、连接或 DHCP 验收。

`k7voice flow-mic-wake` 消费最近一次完成的麦克风录音，将识别结果复制到调用方持有的 256 字节 UTF-8 缓冲区，再送入同一个 Controller。该命令是 ASR 到规则引擎的第一道真机门禁；录音仍由 `k7sound` 独立触发，提示仍输出到控制台。
