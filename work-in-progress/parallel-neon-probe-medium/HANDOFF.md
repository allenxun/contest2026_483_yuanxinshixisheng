# A72 / NEON 短时诊断独立候选

仅写本目录。未操作 SDK、Ubuntu、SSH、COM8、BLE、板子、存储或正式源码；未交叉编译、链接或执行 ARM 汇编。输入/交付 SHA256 见 hashes.json；host-results.json 只证明便携参考算法。

## 集成前必须完成

1. 主代理独占集成；候选源为 probe_main.c、probe.h、neon_hold.S。C 使用 C11，**probe_main.c 必须用 `-mgeneral-regs-only`**，汇编限定 `-march=armv8-a`，不启用 dotprod/i8mm。不能对同一编译命令同时用只允许整数寄存器的选项编译 test_reference.c。
2. 本候选 pthread/affinity/getcpu API 来源是本仓 app/k7load/k7load_main.c；未声称核对远端 SDK 头文件。主代理须核对目标声明、配置、链接、线程栈最小值及定时调度。需 CONFIG_SMP、CPU4/5 online、NEON/FPU 支持。
3. **检查最终反汇编**：checkpoint 和通往 sched_yield 的正常调用链不能把 d8..d15 保存到普通 C 栈再恢复，否则可能掩盖调度保存错误，只能报告“不足以验收”。目标线程上下文保存/恢复本身对这些寄存器的保存是被测行为，不在此禁止范围内。编译器选项只约束本 C 文件，不保证 libc/syscall 调用链。
4. 启动前核对 CPU4/5 均为 A72，CPU0 服务保留；默认继承协调线程调度参数。不提升实时优先级。四个线程按 0/1→CPU4、2/3→CPU5 固定，每核两个线程。未证明 peer_progress 非零的线程不能通过。

## 覆盖与限度

每批汇编加载 16 个不同的精确 float32 整数到 D8..D15，共八个寄存器低64位。调用 C checkpoint 时不 spill/reload 测试值，返回后 ARMv8-A `fadd .2s` 加1，最多32次；回传实际完成步数并逐 lane 比较。每个线程有不同种子。C checkpoint 检查真实 sched_getcpu、sched_yield 返回值，并记录同核伙伴 epoch 在 yield 前后是否变化。固定核加同核伙伴进度证据支持发生实际线程调度；不是仅 volatile 内存测试。

AAPCS64 正常 C 调用只保留 V8..V15 的低64位。其余寄存器、上64位、FPCR/FPSR **不在此次验收内**。即使 PASS，也不等于全部 SIMD 上下文正确：ABI 调用链需上述审核，偶发/值等价污染可能漏检。此测试没有真实 llama 算子、量化矩阵、模型池、模型文件、全核迁移或全系统长期共存覆盖。

## 有界性及失败路径

从 main 开始共用5秒计算截止，协调者8秒等待截止；每批32次、每线程100000批、启动等待1000次、协调等待8000次，均有有限上限。只有四个8192字节请求线程栈、固定静态状态和每线程128字节输入/输出，没有模型分配；pthread实现仍有少量固定线程元数据开销。无启动自动运行，入口只接受无参数；同一静态程序状态只允许运行一次。

每个 pthread/attr 创建设置/销毁返回值都检查。部分创建失败立即 stop，打开 go 让已创建线程退出；协调等待其 done，正常路径 detached 自动回收线程资源。超时不访问未完成线程普通字段，static状态保留且不能重用，无悬空栈参数、无无限 join。不使用异步 cancel。调度器失效、系统调用永久卡住时用户态不能保证墙钟绝对10秒或资源已回收；此时返回 INCOMPLETE，主代理必须核对目标任务组退出语义及存活线程，不能宣称清理完成。正常调度下计算5秒、协调预算8秒，打印/调度开销另计；如要求独立于调度器的硬截止，需外部看门狗而非本候选承诺。

## 静态审核

- 汇编128字节栈16字节对齐；保存/恢复x19..22、x29/x30及d8..15；无x18使用、无未保存callee-saved寄存器。
- 调用回调前/后没有测试d寄存器重载；回调函数地址和context在callee-saved GPR；所有退出路径写64字节output且返回0..32。
- 数值范围0..815，float32整数加1精确，不依赖容差或fast-math；中断路径按实际步数检查。
- go/done使用C11顺序一致原子：deadline发布和结果读取有同步；只有worker写各自普通结果；未完成结果不读取。
- 没有未经证实的目标特定API；但正式目标编译和上述ABI调用链审核尚未进行。

## 主机复核

`python run_host_tests.py` 在本目录生成 reference-test.exe、host-results.json 和 hashes.json。每个子进程10秒超时。测试4种子×33步数=132个正例，2112个逐lane污染拒绝及132个非法步数拒绝。它执行实际 probe.h 参考/比较代码，不执行线程调度或ARM汇编，不替代目标测试。没有把主机测试记录成NEON通过。
