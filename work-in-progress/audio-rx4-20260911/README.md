# SAI RX 四路激活与路由对照

RDE=1、RDL水位16的真机对照没有改变两项有效、六项零的四FIFO循环。本实验保持 S32、16 kHz、双 slot、codec PGA24、PIO 读取和全部时钟不变，增加两个有界命令：

- `capture-pga24-rx4`：只把 RXCR.CSR 从1改为4，保留平台的 SDI0/1/2/3 对应路由。
- `capture-pga24-rx4-all`：CSR=4，并把四个接收 lane 都映射到物理 SDI0。

两臂均保存原始数据，不删除零、不重采样。先运行默认路由，再运行全 SDI0 路由；只有全路由产生连续、速率正确、可复现的采样，且停止/恢复全部通过，才进入实际 ASR 复测。
