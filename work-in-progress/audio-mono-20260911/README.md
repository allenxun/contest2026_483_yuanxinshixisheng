# SAI 接收 Mono 对照

RX4 全路由增加了非零字，但主要值为 `-1/0`，不能作为有效麦克风音频。本候选使用 TRM 明确定义的 `MONO_CR.RX_MONO`，选择 slot0、SDI0 和 CSR=1；每个 16 kHz 帧只读取一个 RXDR word，并在内存中原样复制到左右位置以保持现有 `k7sound_copy_mono` ABI。

该行为不依据样本值删零，不改变标称采样率。命令结束后先停止 RX，再恢复原 MONO_CR。先跑 3200 帧短测；只有实际耗时约 200 ms、数据不再呈四相缺失、停止和恢复全部成功，才进行 48000 帧语音与 ASR 复测。
