# Independent bounded playback filter

`af_filter(src, src_words, dst, dst_words, frames, mode, &saturations)` takes1..48000 interleaved stereo rawuint32 words encoding signed32 audio. Source/destination/count storage must be mutually disjoint, aligned, valid and exclusively owned. Invalid mode/count/capacity/alignment/address-range overflow/overlap returns-EINVAL before writing output or count. C cannot prove arbitrary caller pointer validity. No allocation or hardware dependencies; only playback_filter.c/.h needed on target.

AF_MA4 computes each channel's causal4-point average with zero initial history and integer truncation towardzero. AF_MA4_HP80 then applies `y[n]=alpha*(y[n−1]+x[n]−x[n−1])`; alpha=1040533595/2^30, nearestQ30 approximation to exp(-2*pi*80/16000)=0.9690724263048106. This is an80Hz exponential-pole DC blocker at **nominal16kHz**; not an assertion of the actual hardware sampling rate, and not an exact bilinear80Hz corner design. No floating point in component; test uses math only for expected response.

MA4 group delay1.5nominal samples (93.75us). HP phase delay is frequency dependent. State resets at each API call; process the entire3-second recording in one call. Splitting into multiple calls inserts fresh transients, so this is not a streaming/chunk-continuation API. No lookahead: a longer run preserves the same prefix output. Same number of output frames, no convolution-tail append, no zero deletion, no rate change, no L/R mixing or normalization. Default PIO unchanged; root selects derived destination only for separate playback comparisons.

Each MA sum uses int64. HP difference bound is3*2^31; Q30 product <6.71e18, below INT64_MAX. Division truncates towardzero. Every output sample saturates to signed32 and increments a bounded count (max96000); HP feedback stores the saturated output to avoid unbounded internal state. Any saturation changes linear response and must be reported. Source remains unchanged. This is an audio experiment, not FIFO/sampling repair.

Tests at O0/O2 cover coefficient rounding, independent bipolar impulse, silence/constant/DC decay,50/1000/4000Hz response versus transfer function, fullscale step saturation, preserved prefix continuity, maximum frames/minimum frames, invalid input/capacity/overlap/alignment and untouched output/count on validation failure. First build caught misleading indentation in test code; corrected without disabling warnings. Exact commands/raw output in results.json (30s compile,15s run limits).

Root integration: retain original capture buffer; allocate a separate bounded output buffer, run after capture and before playback, print mode/saturation count, replay derived frames using original rate declaration, then retain both buffers/evidence. Memory requirement at48000frames is384000bytes additional output; component stack state is small. Start MA4 alone; HP mode is a separate comparison. PGA24 increases voice and noise per user; no improved intelligibility is claimed here.
