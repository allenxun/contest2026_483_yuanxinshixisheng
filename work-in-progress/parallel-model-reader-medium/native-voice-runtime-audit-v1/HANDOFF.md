# Native ARM64 NuttX voice runtime audit

**Fast result: existing models are usable inputs, but no native ARM64 NuttX sherpa/ONNX inference library or complete inference source tree was found in the inspected local inventory. This task did not run Windows inference, use PC-assisted audio, download dependencies, or access SDK/devices.** The next deliverable must be a native cross-built runtime, not a wrapper around the existing host DLLs.

## Verified local assets

Both inspected runtime DLL PE headers have Machine=0x8664 (AMD64 Windows), not ARM64 NuttX. Linux ARM64 .so, even if acquired later, would also not establish NuttX ABI/syscall compatibility.

Missing before link: full pinned sherpa and ORT source/dependency/license closure, NuttX cross-build configuration and required CPU kernels for these ONNX graphs; target C++ runtime/exceptions policy, pthread/TLS/condition variable/time support, file/mmap environment layer and allocation policy. Exact transitive libraries (feature extraction, FAR/FST/text normalization, model kernels and serialization build tools) must be resolved from the full pinned CMake sources; headers/Windows import libraries cannot supply that closure. Do not invent a ready NuttX build command or claim a header-only integration. CPU provider/one thread is the initial intent, not proof all library internal threads disappear. Existing llama ARM64/ggml gates do not establish ORT portability.

## Smallest board-only acceptance sequence

1. Root obtains/builds a **static native ARM64 NuttX** sherpa C API + ORT CPU runtime from pinned sources in an isolated target build; compile/link audit must resolve actual platform calls and required model operators. No fake success stubs. This audit did not download/build it. First root-run probe prints library version and actual allocation/time results, and fails closed on unsupported OS/runtime functions.
2. Choose ordinary read-only paths such as `/mnt/k7model/asr/{encoder.int8.onnx,decoder.int8.onnx,tokens.txt}` and `/mnt/k7model/tts/{model.onnx,tokens.txt,lexicon.txt,rule.far}` **only after root provisions/verifies the medium and names**. Input manifests must follow any intentional renaming; do not duplicate big weights in firmware. Hash/length-check model set and keep mount stable while runtime opens/holds it.
3. **ASR-only native WAV probe:** bounded ordinary mono PCM16 WAV at16000Hz; this avoids depending on disputed live microphone demux. Use OnlineRecognizer Paraformer, CPU num_threads1, feature_dim80 (not560), greedy_search; feed bounded512-sample float chunks, InputFinished, drain, destroy result/stream/recognizer. Record actual text, elapsed and peak/free memory, cold/warm run, failure cleanup. Native file reading/inference/output is the acceptance; no PC processing or expected-text substitution. Full inference timeout/abort requires verified library handling; application polls alone cannot hard-stop an in-flight call.
4. **TTS-only native probe:** short fixed public Chinese text, VITS sid0/speed1, selected tokens/lexicon/rule.far; retrieve actual samples/sample_rate, count/peak/hash in RAM, destroy generated audio and engine. This model outputs **8000Hz mono**, not16000. A read-only model volume cannot accept output WAV writes; first use bounded RAM output, then root-approved sink or a separately writable output location. Speaker playback requires verified8k codec mode or a separately tested rate conversion; never relabel8k as16k. No cloud or host synthesis.
5. Only after each actual native probe and cleanup passes, integrate a serial VoiceLink worker with separate model lifecycles, real board audio and already-reviewed shared radio arbitration. Keep Wi-Fi IP success semantic; do not turn unimplemented ASR/TTS into fake recognized text/prompts.

Historical Windows memory is a warning for sizing, not target acceptance: ASR RSS550662144/private792666112; TTS RSS311459840/private303878144; concurrent binding RSS812953600/private1026174976. 20ms sampling can miss peaks. A~126MiB ordinary heap cannot be assumed adequate, and the explicit1GiB pool is not automatically usable by any of those paths. Measure native runtime allocations before promising simultaneous models.

No source patch is justified without the missing runtime source/platform closure. This is a concrete compile prerequisite, not a proposal to keep testing on PC. Model hashes and native probe definitions are ready for the main task's board-only integration.
