# 加载与交互优化记录

## 本轮修复（按风险顺序）
1. 报告列表去除固定约24秒的装饰性等待，直接进入实际加载方案的页面。
2. 旧护理流程保留原指令/时序，启动指令写入成功后才提示“指令已发送”，不宣称设备实际启动；停止提示同样区分发送与执行。
3. 摄像头增加连接20秒、取帧10秒响应监控；超时使旧任务失效，提示检查设备，原生调用未结束时不堆积新连接。无法安全强杀native永久阻塞。
4. 首页、设备历史初次加载去重并增加请求互斥；保留设备历史搜索条件。
5. 人员列表区分加载/空/错误并可重试；按设备查询失败不再退回全部人员。
6. 聊天流式更新间隔48ms、相应增加每次字符数；仅更新文字，不重复绑定头像或复制整张消息列表。
7. 分析计时器支持暂停恢复；销毁清理计时、动画、延迟跳转；后台完成等待恢复后跳转。
8. openVela查询引入QUERYING状态，等待期间禁止重复提交，超时恢复重试。
9. Wi-Fi列表改为280dp独立滚动容器，保持条目复用，不改变返回数据和排序规则。
10. 首页轮播（尚无详情接口）接入图片预览；旧方案/三视图也可应用内预览、双指缩放、拖动、双击还原，加载失败可重试。
11. 记录卡片/主按钮加入按压反馈与禁用颜色。
