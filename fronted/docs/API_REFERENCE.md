## 4. 测肤分析

> **整体流程：**
> 1. 拍照/选图 → 上传图片到 OSS（见 [8. 文件上传](#8-文件上传oss)）
> 2. 携带 `oss_key` 跳转报告页
> 3. 报告页调用分析接口 → 服务端生成报告 → 返回报告数据

### 4.1 提交皮肤分析（生成报告）

| 项 | 值 |
|---|---|
| **方法** | `POST` |
| **路径** | `/api/self-research-face/analysis` |
| **认证** | ✅ |
| **调用位置** | `SkinReportActivity.kt:1096` |

**请求参数（JSON Body）：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `oss_key` | string | ✅ | 上传到 OSS 后的文件 key |

**使用场景：** 用户在 `SmartSkinTestActivity` 拍照确认后，图片上传到 OSS 获得 `oss_key`，跳转到 `SkinReportActivity`，该页面调用此接口触发后端分析生成报告。接口返回后页面展示完整的测肤报告（肤质类型、评分、雷达图等）。

## 8. 文件上传（OSS）

> **上传流程（两步直传）：**
> 1. 获取 OSS 上传凭证
> 2. 用凭证直传文件到 OSS
> 3. 上传成功后获得 `oss_key = dir + filename`

### 8.1 获取 OSS 上传凭证

| 项 | 值 |
|---|---|
| **方法** | `GET` |
| **路径** | `/api/oss/upload-params` |
| **认证** | ✅ |
| **调用位置** | `SmartSkinTestActivity.kt:822` |

**返回字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `host` | string | OSS 上传地址 |
| `policy` | string | 上传策略 |
| `OSSAccessKeyId` | string | 访问密钥 ID |
| `signature` | string | 签名 |
| `dir` | string | 存储目录前缀 |

**使用场景：** 所有图片上传（测肤 skin、3D 面诊 3d、美颜 face）统一使用此流程：
1. 先调此接口获取凭证
2. 再用凭证通过 `multipart/form-data POST` 直传文件到 OSS `host`
3. 上传成功后 `oss_key = dir + filename`，用于后续分析/建模接口
