# 全项目稳定性修复记录

本轮按摄像头原生资源、照片内存、3D模型、录音、生命周期和网络异常的顺序修复。此前 openVela 稳定性修复保留。

## 改动
- WifiCamera 的创建、访问和销毁使用同一串行锁，并校验有效句柄；销毁等待发生在后台线程。
- 摄像头连接使用单线程队列、连接批次和取消标记；过期连接回收自己的句柄；预览最多一帧等待 UI 显示。
- 照片方向修正、JPEG压缩和文件替换移到后台；先读尺寸再采样，工作位图长边不超过2048；写入临时文件成功后替换，失败不覆盖原文件。
- 人脸模型初始化、检测、关闭放入同一个队列；任务图像显式关闭；退出后丢弃结果。
- 3D模型流式落盘，经应用拦截的同源本地HTTPS地址向WebView提供二进制数据，移除整包Base64桥接；退出取消请求和清理临时模型。
- 录音PCM直接写文件并补齐原WAV头；停止等待和Base64编码放在后台；录音批次避免旧线程重新运行。
- 隐藏首页停止轮播；报告生成取消清理全部相关延迟任务；旧养肤设备跳转按视图生命周期失效。
- 通用网络响应正文读取抛IOException时明确通知业务失败，避免一直加载。

## 输入保护及兼容边界
- 高分辨率照片会采样到长边不超过2048再标准化并上传，可能改变原图分辨率；需确认后端测肤质量满足要求。
- 3D下载超过128MiB明确失败，不再尝试无限内存加载。
- 录音单段5分钟自动结束；超过16MiB不做Base64编码，提示分段录制。
- 现有接口路径、WAV音频格式、蓝牙指令和护理操作未调整。
- 原生.so内部崩溃/永久阻塞无法仅凭Android层代码保证消除。

## 验证
- 全项目Kotlin隔离类型检查通过。因本机SDK不完整，此检查使用仅位于app/build的资源符号fixture；不是正式Android资源链接或APK构建。
- 12项JUnit测试通过：蓝牙分包解析、监听所有权、照片采样边界。
- 3D内联JavaScript语法及二进制加载成功、HTTP失败、取消三种场景通过。
- 正式Gradle构建失败于找不到android-36.1 SDK。没有把类型检查当作APK构建通过。
- 未安装本轮APK，未验证摄像头硬件、MediaPipe native并发或WebView实际资源拦截。
