## 刷新规则

总协调每次半小时巡检后，以及收到完成或阻塞报告时，运行：

```bash
python3 backend/doc/tasks/update-panels.py
```

脚本只读取 `.coordination/registry.json` 和各包 `status.json`，不会调用模型或 OpenCode。巡检依赖电脑与任务正常运行；时间未更新时应视为旧快照。

首次面板纳入 Git；后续快照按里程碑提交，避免每次巡检产生一个提交。托管文档站点是发布快照，不会自动同步这些本地任务面板。
