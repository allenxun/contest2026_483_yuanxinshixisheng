## 网页版

`site/` 保留可编辑源码与锁定依赖清单，`web/` 保留可直接用静态 HTTP 服务阅读的构建结果。源码、静态页面统一纳入本项目 Git，不复制旧 `.git`、密钥或运行缓存。

在本目录运行：

```bash
python3 -m http.server 3000 --bind 0.0.0.0 --directory web
```

打开 http://localhost:3000/ 。局域网访问使用本机局域网 IP。网页包含详细设计、人脸调研、技术架构、数据架构、测试、组件、模块、用例、流程和 API 共十个入口。页面必须由 HTTP 提供，不保证 file:// 双击运行。

更新源文档后，在 `site/` 执行：

```bash
npm ci
python3 scripts/import-docs.py
npm run build
```

build 自动将静态结果同步至 `../web/`；生成文件不手工改。仅新增或更新生成结果中的现行下载文件，不积累旧快照。

托管站点继续关联原 Sites 项目，当前访问范围保持原配置。迁移不自动发布；之后发布需明确请求，并仅导出 site 子目录用于托管，绝不上传整个项目源码。
