# K7 前端交接：蓝牙配网与联网成功回报

更新：2026-09-14。本文按当前 `vela-provision.mjs`、板端 `prov_protocol.c`、`prov_service.inc` 核对。可直接交给 App 开发。

## 目标流程

App 连接 K7 蓝牙并订阅通知 → 发送单字节 `X` → K7 扫描并逐条返回 Wi-Fi 列表 → 用户选择网络、手动输入密码 → App 提交连接命令 → K7 连接 Wi-Fi 并取得 DHCP 地址 → **K7 主动向 App 通知 `wifi_connected` 和 IP，App 显示“联网成功”** → K7 喇叭播放“联网成功”。

联网成功消息由板端真实连接结果触发。BLE 写入成功、收到密码、App 自己能上网均不能代替该消息。语音输入密码不属于本流程。

## 1. BLE 通道

| 用途 | UUID | 操作 |
| --- | --- | --- |
| 服务 | `6b7a0001-78c3-4f2e-9c2f-3ecbc2d74680` | Discover |
| App → K7 | `6b7a0002-78c3-4f2e-9c2f-3ecbc2d74680` | Write with response |
| K7 → App | `6b7a0003-78c3-4f2e-9c2f-3ecbc2d74680` | Notify，先订阅再发送命令 |
| 能力查询 | `6b7a0004-78c3-4f2e-9c2f-3ecbc2d74680` | Read |

先完成系统配对/加密，确认能力返回 `encrypted:true`、`connect:true`，记录 `session`。能力 Read 是完整 JSON；Notify 是 UTF-8 JSON Lines，必须缓存字节到换行后再解码/解析，不能将一次 BLE 回调当作完整消息。

写入保守按每包不超过 20 字节顺序发送，等上一包写入成功再发下一包。同一连接只保留一个未完成请求。JSON 命令末尾加 `\n`，整条不超过 512 字节；`X` 是单独一个 ASCII 字节 `0x58`，无需换行。

## 2. 发送 X 获取列表

App 写入 `X`。板端为本次扫描生成 id，返回如下示例，每行实际以换行结束：

```json
{"v":1,"id":1,"event":"scan_started"}
{"v":1,"id":1,"event":"ap","ssid_b64":"TGFuc2Vl","rssi":-48,"security":"rsn","band":"2.4G","channel":6}
{"v":1,"id":1,"event":"scan_done","count":1,"truncated":false}
```

从 `scan_started` 绑定本轮 id，逐条累计 `ap`，收到 `scan_done` 后完成列表。界面可自行显示序号；选择后提交该条原始 `ssid_b64`，不要把显示名重新编码后提交。示例 `TGFuc2Vl` 对应 Lansee；RSSI 越接近 0 信号越强。`truncated:true` 表示列表截断。

当前已联网时扫描不可用，前端先查 status；不要为刷新列表自动断网。扫描建议超时 60 秒。空列表也是一次正常完成。

## 3. 用户选择 Wi-Fi 并提交密码

```json
{"v":1,"id":101,"cmd":"connect","ssid_b64":"TGFuc2Vl","password":"example123"}
```

这是示例密码。id 为 App 生成的 1～65535 整数，逐次递增。SSID 原始长度 1～32 字节；当前密码支持 8～63 个可打印 ASCII 字符，优先用 WPA2-PSK 网络联调。扫描能显示某种网络不代表支持连接它。当前不支持用空密码连接开放网络。

**必须使用 `cmd:"connect"` / `connectWifi()`。** `submit_credentials` / `submitCredentials()` 仅校验收到的输入，不会发起真实连接。

## 4. 板端回报连接结果（App 必须接入）

连接进行中：

```json
{"v":1,"id":101,"session":7,"event":"wifi_connecting"}
```

真正取得地址后，K7 通过 Notify 主动返回：

```json
{"v":1,"id":101,"session":7,"event":"wifi_connected","wifi_connected":true,"ip":"10.3.0.214","stored":false}
```

App 校验本次请求 id、当前 session、`event:"wifi_connected"`、`wifi_connected:true` 和有效非零 IPv4 后显示“联网成功”，展示实际 IP 并结束等待。示例 IP/session 不可写死。`stored:false` 表示凭据没有持久保存，断电后不能承诺自动重连。

产品要求：板端在同一真实成功状态后播放一次本地“联网成功”，播放不依赖云端 TTS；不要阻塞 BLE 回包，也不要因播放失败把已连接状态伪装为连接失败。**成功 Notify 已在板端源码实现；本轮新固件的 App 实测及自动播报闭环仍待验收。当前协议没有“喇叭已播放完成”事件。**

连接失败示例：

```json
{"v":1,"id":101,"session":7,"event":"error","code":"authentication_failed","detail":-13,"wifi_connected":false,"ip":null}
```

处理 `invalid_ssid`、`invalid_password`、`network_not_found`、`unsupported_security`、`authentication_failed`、`connection_timeout`、`connection_failed`、`busy`、`not_ready`。连接等待最多 120 秒；失败提示用户修改或重试。不要将所有失败都显示为密码错误。

## 5. 断开重连或等待超时后的状态恢复

BLE 断开后将界面连接状态标记为“未知”，清空待处理请求和半包。重新连接、订阅、读取新 session 后发送：

```json
{"v":1,"id":102,"cmd":"status"}
```

板端回复示例：

```json
{"v":1,"id":102,"event":"status","wifi_connected":true,"ip":"10.3.0.214","session":8}
```

用该结果恢复展示，避免成功回包在蓝牙断开时丢失后重复提交密码。当前不能假设所有后续 Wi-Fi 断链都有主动推送；需要状态时主动查询。Wi-Fi 获得 IP 只代表局域网连接成功，DNS、互联网和云语音可用状态另外验证。

## 6. uni-app 可直接复用的客户端

同目录 `vela-provision.mjs` 无第三方依赖，包含拆包、串行写入、请求/session 匹配与超时处理：

```js
import { VelaProvision } from './vela-provision.mjs';

const ble = new VelaProvision(uni, {
  onAccessPoint: ap => { /* 可逐条展示 ap，保留原始 ssid_b64 */ },
  onWifiState: event => { /* wifi_connecting 时显示连接中 */ },
  onConnection: connected => { /* false 时标记蓝牙断开 */ }
});

await ble.connect(deviceId); // deviceId 来自 App 蓝牙发现列表
const rows = await ble.scan(); // 内部先查状态，再发送 X
// 用户在 rows 中选择 selected，表单输入 password
try {
  const result = await ble.connectWifi({
    ssid_b64: selected.ssid_b64,
    password
  });
  // Promise 只有在收到匹配的真实 wifi_connected 时才成功
  showConnected(result.ip); // App 自己的界面函数
} catch (error) {
  showConnectError(error.code || error.message);
} finally {
  password = ''; // 同时清空密码输入框，不写日志或持久化
}
// 页面销毁时 await ble.dispose()
```

扫描超时和连接异常也应由页面外层捕获。已有客户端的 `onWifiState` 用于连接中通知；成功结果以 `await connectWifi()` 返回值处理，不要只在该回调里等待成功。

## 7. 联调验收与云语音边界

双方一起验证：X 后收到列表及 scan_done；提交正确密码收到 wifi_connecting → wifi_connected/IP；App 显示成功、K7 实际说出“联网成功”；错误密码不显示成功；重连后 status 恢复真实状态。

云语音接口另见 `蓝牙联网与流式语音联调.md` 和 `speech-service-stream.mjs`。当前 speech-service 实现采用阿里云；不能标成已验证的小米 MiMo 流式服务。前端不持有厂商 API Key。蓝牙成功通知不代表板端麦克风到云 ASR、云 TTS 到喇叭已全链路验收。
