## 请求与回包

以下密码仅为格式示例，不能用于实际验证：

```json
{"v":1,"id":101,"cmd":"connect","ssid_b64":"TGFuc2Vl","password":"EXAMPLE_ONLY_123"}
```

末尾加实际 LF 换行，UTF-8 编码，每片不超过 20 字节，依次等待写入成功；所有片段应在 10 秒内发完。每个会话同时只允许一个请求。JSON 总长度不超过 512 字节。适配器已实现分包及按行组包。

```json
{"v":1,"id":101,"session":1,"event":"wifi_connecting"}
{"v":1,"id":101,"session":1,"event":"wifi_connected","wifi_connected":true,"ip":"10.3.0.214","stored":false}
```

示例 IP/session 不能硬编码。按相同 `id` 和能力读取到的 `session` 匹配回包，忽略旧会话事件。中间事件不能当作成功。

失败示例：

```json
{"v":1,"id":101,"session":1,"event":"error","code":"connection_timeout","detail":-110,"wifi_connected":false,"ip":null}
```

输入校验失败可直接返回 error，无 wifi_connecting，也不包含网络状态字段。底层错误可能保留已有网络，例如 busy；只要是 error 就不能视为本次请求成功。

| code | 处理 |
|---|---|
| invalid_ssid | 必须是规范 Base64，解码后 1–32 字节 |
| invalid_password | 8–63 个可打印 ASCII 字符，空格/反斜杠按原值传递 |
| network_not_found | 当前扫描没找到指定 SSID，不能保证隐藏网络可用 |
| unsupported_security | 当前支持 WPA2-PSK/CCMP，开放网、企业网、WPA3/必需 PMF 尚未支持 |
| authentication_failed | 认证失败，不一定能够证明密码错误 |
| connection_timeout | 认证或 DHCP 等待超时，不写成确定密码错误 |
| busy | 上个无线操作或清理尚未结束，等待后重试 |
| connection_failed | 其他驱动/网络错误，保留 detail 给设备端定位 |
| not_ready | 固件能力未接入，检查版本 |

`submitCredentials()` 仍只回复 `credentials_received`，不联网；不要把旧 OK 当作新接口的成功。

## 断开、切换和隐私

连接请求会主动停止已有 Wi-Fi 网络，再尝试指定网络；失败不会自动回滚旧网络。BLE 中途断开后，已开始的联网操作继续完成；旧结果不会发送给新 BLE 会话，重连后调用 status 查询，不能自动重复提交密码。当前没有持久保存密码、开机自动联网或长期断网自动重连。

密码只用于本次认证，操作结束后擦除请求缓冲；WPA 会话密钥保留用于正在工作的连接。不要记录请求 JSON、密码或完整 ATT 载荷。App 应在成功/失败后清空密码输入。
