# 完整配网待实现契约（设计草案，禁止用于当前固件）

本文用于对齐设备端待办。以下字段、规则和事件尚未实现或真机验收；不能据此启用密码提交。当前正式接口见《前端对接说明》；设备端仍为 `connect:false`。

## 拟定首版范围与提交

首版拟限定 WPA2-Personal / PSK / CCMP；不支持企业认证、WPA3-only、需要 PMF 的网络、原始 64 位十六进制 PSK 或开放网络配网。扫描 `security:rsn` 不能证明 AP 满足这些条件，必须由设备端解析 AP 安全能力后决定。

拟沿用加密 GATT Write、UTF-8 JSONL、20 字节串行分片和最多 512 字节整条命令：

```json
{"v":1,"id":103,"cmd":"connect","ssid_b64":"TGFuc2Vl","password":"EXAMPLE_ONLY_123"}
```

此密码仅为格式示例，不是真实凭据。`id` 为 1..65535 整数；`ssid_b64` 必须是标准 Base64，解码后 1..32 字节，保留扫描返回的原始字节。拟定密码范围为 **8..63 个可打印 ASCII 字节（0x20..0x7e）**；保留首尾空格和反斜杠，不 trim、不自动添加字符；JSON 转义交给 `JSON.stringify`。非 ASCII、控制字符、NUL、长度不符应返回 `invalid_password`。不保存或记录密码，也不在断线重连后自动重放。

这是首版主动限定的支持范围，不代表所有 Wi-Fi 网络只接受上述密码。当前解析器仅预留字段名，还没有实现这些校验或密码认证。

## 拟定事件和事务

应用以当前 BLE `session` 与 `id` 共同识别事务；进行中的 id 不复用。设备端串行处理联网操作，每个接受的事务最多一个终态。分片仍按当前 JSONL 协议。

```json
{"v":1,"session":31,"id":103,"event":"connect_progress","stage":"associating"}
{"v":1,"session":31,"id":103,"event":"connect_progress","stage":"authenticating"}
{"v":1,"session":31,"id":103,"event":"connect_progress","stage":"dhcp"}
{"v":1,"session":31,"id":103,"event":"connect_result","ok":true,"code":"ok","wifi_connected":true,"ip":"192.0.2.10"}
{"v":1,"session":31,"id":104,"event":"connect_result","ok":false,"code":"auth_failed","wifi_connected":false,"ip":null}
```

成功与失败示例是不同事务，IP 是文档示例地址。只有完成密钥安装、取得有效 DHCP 租约后才发送成功；获取 IP 不代表互联网可达。拟定错误码：`invalid_ssid`、`invalid_password`、`unsupported_security`、`ap_not_found`、`association_failed`、`auth_failed`、`dhcp_timeout`、`driver_error`、`busy`、`cancelled`。密码错误、AP 拒绝或握手超时不能一律冒称“密码错误”，无充分证据时用 `auth_failed`。

断开 BLE 时取消未完成事务、清理敏感缓冲区；无法继续通知的结果不跨 session 补发。重连后主动查状态，不重放原密码。状态查询需返回实际连接状态和 IP；已连 Wi-Fi 后的异步掉线通知、超时参数、联网持久化策略仍待实现时定稿。

## 开启 connect:true 前的设备端验收

- 正确密码：真实 WPA 握手、PTK/GTK 安装、DHCP、网关或指定局域网服务实际通信成功；保存时间、固件哈希、脱敏串口及事务事件。
- 错误密码、AP 消失、不支持的安全配置、DHCP 不响应：得到对应失败终态，不残留假 IP 或成功状态。
- 配网中断开 BLE、重连、重复提交：无旧事务串入新 session，不重发密码，不泄露密钥。
- Wi-Fi 持续收发期间进行 BLE GATT 通信和重连：检查异常断连、超时和内存变化。
- Android/iOS App 分别记录客户端版本、手机系统、结果；不能用 Node Mock 测试代替。

完成上述设备端工作后发布正式固件、正式协议/适配器和真机报告；届时才将能力改为 true。
