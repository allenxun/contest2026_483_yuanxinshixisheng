# 当前可用联调入口

语音电脑地址：`http://10.3.1.125:8000`。本机和 Ubuntu 已分别 GET /health 成功。
已允许浏览器来源 `http://10.3.3.68:3000` 的 GET/POST；其他网页来源需要由服务端
通过 `K7_FRONTEND_ORIGINS` 添加，HTTPS 页面调用 HTTP 会受到浏览器混合内容限制。
原业务后端 `10.3.3.170:18085` 的 API 与此语音服务分开。

1. 使用既有 `vela-provision.mjs` 连接 BLE，扫描并发送用户选定的 SSID/密码。
2. 必须收到板端 `wifi_connected` 和实际 IP，再检查 `status()`；提交成功不代表联网成功。
3. 前端显示已联网；板端本地播报“联网成功”仍需实际固件配置/验收。
4. 语音：`GET /health` 检查服务、`POST /tts {"text":"联网成功"}` 得到16k mono S16LE PCM。
5. `WS /asr/stream` 持续传20ms PCM，收 partial/final。协议见主仓
   `docs/speech-service流式ASR接入_20260914.md`；JS适配器为 `speech-service-stream.mjs`。

```js
import {speechService} from './speech-service-stream.mjs';
const speech = speechService('http://10.3.1.125:8000');
const stream = speech.stream(event => {
  // ready后才开始送录音。partial覆盖当前句，final固定当前句；completed才结束会话。
  console.log(event.type); // 产品日志不要记录凭据和用户录音内容。
});
// 当录音模块提供一个16kHz单声道PCM16LE块（320样本、640字节）：
// if (stream.ready) stream.sendPcm(pcmChunk); // false时保留原块，等待ack再试。
// stream.stop(); // 输入结束；继续等待final/completed。
// const {pcm} = await speech.tts('联网成功'); // 裸PCM不能直接当WAV传给audio标签。
```

当前真实云合成句已验：TTS1219ms、ASR640ms首个非空文字；这不是K7麦克风验收。
此服务使用阿里云百炼；MiMo候选仍保留，不能写成“小米流式已通过”。
